Support

Answers to the questions people actually ask, and how to reach a person.

Write to yjia2175@gmail.com any time. Replies usually come within a day or two. If a copy failed, attach the diagnostics log (see the end of this page); it saves a lot of back and forth.

Getting started

How do I keep a photo or video?

Tap + and choose Choose from Photos, then pick one or more items. Untouched copies each item’s original files. If an original is only in iCloud, it downloads first. Keep the app open until the progress row finishes.

It says “Full access required”. Why?

The photo picker only tells an app which library item you chose when the app has full access, and that’s the only way to reach the original files. Go to Settings › Untouched › Photos › All Photos. Untouched only reads your library; it never edits or deletes anything in it.

Why is there no percentage on the progress bar?

iOS doesn’t tell apps how big an original is before it arrives, so any percentage would be invented. Untouched shows the real amount retrieved so far and the download speed instead.

Can it copy new photos automatically?

No. Downloading large originals from iCloud takes longer than iOS allows apps to run in the background, so copying happens while the app is open, for the items you choose.

The Hidden album

Can I keep items from the Hidden album?

Yes. If the Hidden album is locked with Face ID, iOS doesn’t hand apps the full item, so Untouched keeps the single file the system gives it. It’s marked Picker copy (single file) in the item’s details, and if the original had been offloaded to iCloud, that file may be the smaller version. For the complete original with all its files, turn off the lock in Settings › Apps › Photos while you add the item, then turn it back on. Turning off the lock doesn’t unhide anything.

Your files

Where are my files?

In Files › On My iPhone › Untouched. Each item is a folder named with its date and file name, containing the original files: for example original-IMG_2041.HEIC, and for a Live Photo also live-IMG_2041.MOV.

How do I get them onto a computer or a drive?

On a Mac, connect your iPhone, select it in the Finder sidebar, open the Files tab and drag the Untouched folder out. Or, in the Files app, copy the folders to a connected drive. For a single item, open it in Untouched and tap Export original…. The files open without Untouched.

How do I check that a file hasn’t changed?

Open an item and tap Verify integrity, or check everything at once in Settings › Integrity › Verify all files. Untouched recomputes each file’s SHA-256 checksum and compares it with the one recorded when the file went in.

Are my files in my iCloud Backup?

Not by default. The originals usually already exist in iCloud Photos, so Untouched leaves its folder out of your device backups to avoid paying for the same files twice. To include them, turn off Exclude from iCloud Backup in Untouched’s Settings. Either way, if you switch phones, copy the Untouched folder to a computer or drive first.

What happens if I delete the app?

iOS deletes the app’s folder along with it, including everything kept in Untouched. Copy your files somewhere else first.

Does deleting an item in Untouched delete it from Photos?

No. Deleting in Untouched removes only its copy. Your photo library is never touched. Note that swiping to delete in the list doesn’t ask for confirmation.

Purchases

What’s free?

You can keep one item for free with no time limit. If you delete it, you can add a different one. To keep more, subscribe ($3.99 a month or $14.99 a year) or buy once for $24.99. US prices; the App Store shows yours.

What happens to my files if I stop paying?

Nothing. You can still open, verify, export and delete everything. Paying only unlocks adding more.

I bought it but another iPhone isn’t unlocked

Open the upgrade screen and tap Restore. Both iPhones need to be signed in with the same Apple Account.

How do I cancel a subscription?

In Settings › [your name] › Subscriptions. Subscriptions renew automatically until you cancel at least 24 hours before the period ends.

Sending a diagnostics log

If a copy failed, tap the gear icon, then Diagnostics › Share log file, and attach it to your email. The log records each step of each copy. It’s stored only on your iPhone and includes file names, so it leaves your phone only if you share it.
