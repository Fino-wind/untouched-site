Untouched · 把丢不起的原件留在本机

先说这个 App 到底在解决什么。 iCloud 从不压缩你上传的东西——云端那份永远是完整原件。 「优化 iPhone 储存空间」做的是把本机那份清掉、只留一个小预览， 你看到的画质下降是这么来的。而 Apple 没有提供把单个项目标记为「留在本机」的开关， 也没有任何 API 能做到。所以 Untouched 的办法是：把原始文件复制一份到自己的文件夹， 那里不受清理机制影响。

常见问题

为什么需要「所有照片」权限？「选中的照片」不行吗？

不行，这是系统的限制而不是我们的选择。只有在完整访问权限下， 照片选择器才会回传资源标识符，而那是读到原始文件的唯一途径。 在受限权限下，App 拿到的是系统转码后的副本——那恰好是这个 App 要避免的东西。 权限只用于读取，Untouched 从不修改或删除你相册里的任何内容。

隐藏相册里的项目存不进来

当隐藏相册开着面容 ID 锁时，iOS 不会把文件交给任何 App。两条路：

  1. 暂时关掉锁：设置 → 照片 → 关闭「使用面容 ID」。 注意关掉锁不等于取消隐藏，那些照片仍然不出现在主相册里， 变的只是打开那个相册要不要再验一次身份。存完随时可以开回来。
  2. 走「文件」：在照片 App 里选择 → 分享 → 存储到「文件」， 存在「我的 iPhone」下任意位置，再回到 Untouched 用「+ → 从『文件』导入」。

存进去的文件怎么拿出来？

打开「文件」App →「我的 iPhone」→ Untouched。每一项是一个名字可读的普通文件夹， 里面是原始文件，可以直接拖到电脑、移动硬盘，或者 AirDrop 出去。 不需要经过 Untouched，也不需要这个 App 还装着。

如果我不续费了，已经存的文件会怎样？

一个都不会少。付费只解锁「继续存新的」，从不影响已经存进来的东西—— 不锁定、不隐藏、不降低画质。技术上我们也做不到：那些文件在你手机的普通文件夹里， 你随时能拿走。这一点是刻意设计的。

删掉 App 会怎样？

会连同 Untouched 的文件夹一起删除。如果打算卸载，请先把文件拷走。

文件会被压缩或转码吗？

不会。复制的是逐字节相同的原始文件——同编码、同码率、EXIF 原样保留。 每一项在存入时都会计算 SHA-256 校验值，你随时可以在 App 里重新校验， 确认文件没有悄悄损坏。

为什么进度条没有百分比？

因为没有可信的分母：系统不提供资源的字节数， 连它自己的进度值都标注为「近似」。编出来的百分比只会卡在 99% 或者跑完了还在转。 所以 Untouched 显示的是实际测量到的已取回字节数和速率—— 分子和速度都是真的，只是不假装知道总数。

能自动归档新拍的照片吗？

暂时不能。几个 GB 的文件从 iCloud 取回所需的时间，超出了 iOS 给后台任务的配额， 所以归档需要 App 在前台。

购买之后在另一台设备上没有解锁

打开付费页面，点右上角「恢复购买」。请确认两台设备登录的是同一个 Apple 账户。

还是没解决？

直接写信，一般一两天内回复。如果是某次归档失败， 麻烦在 App 里打开设置 → 诊断信息 → 分享日志文件并附上—— 那份日志记录了每一步发生了什么，能省掉很多来回。
